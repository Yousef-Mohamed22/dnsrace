> اعثر على أسرع خادم DNS **لاتصالك أنت**، ثم طبّقه بنقرة واحدة.

أفضل خادم DNS يعتمد على مكانك وعلى مسار حركة المرور لدى مزود الإنترنت، لذلك لا تستطيع قائمة
أفضل 10 خوادم من الإنترنت أن تخبرك أيها الأسرع لك. يقيس dnsrace خوادم DNS العامة من جهازك،
ويرتبها حسب زمن الاستجابة الفعلي، ويفحص سلوكها الأمني، ويمكنه تحويل نظامك إلى الخادم الفائز.

**يعمل dnsrace 0.9.0 على سطح المكتب وأندرويد 8.0 فأحدث.** يستطيع تطبيق سطح المكتب تطبيق DNS
واستعادته. أندرويد منصة قياس وإعداد موجّه: يقيس dnsrace الخوادم ثم يساعدك على إدخال الفائز في
Private DNS (أندرويد 9 فأحدث) أو DNS لكل شبكة Wi-Fi (أندرويد 8.0–8.1). لا يوجد إصدار iOS أو
هدف آخر لهواتف Apple، ولا VPN ولا خدمة تعمل في الخلفية. تتوفر واجهة سطر أوامر للبرامج النصية
والخوادم.

## المزايا

- **واجهة عربية بتخطيط كامل من اليمين إلى اليسار.** كل الشاشات والنوافذ ودليل أندرويد مترجمة.
  اختر العربية أو الإنجليزية أو لغة الجهاز من الإعدادات؛ ينعكس شريط التنقل السفلي والجانبي
  والبطاقات ومحاذاة الجداول. خط Noto Sans Arabic مضمّن، لذلك لا تحتاج إلى خط من النظام.
- **تحديثات مدمجة.** يتحقق dnsrace من أحدث إصدار على GitHub عند البدء (اختياري) ومن الإعدادات.
  تُتحقق تنزيلات Linux وWindows وmacOS مقابل ملف `SHA256SUMS.txt` في الإصدار، ثم تُثبَّت في
  مكانها ويعيد التطبيق التشغيل. على أندرويد يُنزَّل ملف APK الجديد ويُفتح مثبّت النظام.
- **واجهة واحدة متكيفة لسطح المكتب والهاتف.** سطح المكتب يستخدم شريط تنقل جانبي وجدول خوادم
  كثيفاً ولوحة تفاصيل. أندرويد يستخدم شريط تطبيق وتنقلاً سفلياً وأزرار لمس 48 dp وبطاقات
  خوادم ونوافذ سفلية. يتكيف تخطيط الهاتف تلقائياً مع شاشات 360 dp و320 dp دون تمرير أفقي.
- **أندرويد 8.0 فأحدث.** الحد الأدنى API 26، والهدف API 36، مع مكتبات `arm64-v8a` و
  `armeabi-v7a` و`x86_64` في ملف APK واحد. التطبيق 100% بلغة Rust؛ لا يوجد كود Java أو
  Kotlin أو Shell.
- **إعداد Private DNS موجّه.** يحصل أندرويد 9 فأحدث على اسم مضيف DoT مقيس (أو اسم مضيف المزود
  مع وسم واضح عندما تتوفر بيانات وصفية فقط) واختصار إلى شاشة Private DNS. يحصل أندرويد
  8.0–8.1 على خطوات DNS لكل شبكة Wi-Fi بدلاً من ذلك.
- **كشف تلقائي لـ DNS على Linux وWindows وmacOS وأندرويد.** يقرأ dnsrace الخوادم التي يستخدمها
  جهازك فعلاً، ويعرض الواجهة النشطة والبوابة ومصدر الكشف، ويسمي العناوين المعروفة بمزودها (مثل
  `1.1.1.1 (Cloudflare)`).
- **ملفات اختبار.** سريع، متوازن، شامل أو مخصص. يضبط الملف المهلة والمهام والتكرار والجولات
  المخزنة والاستعلامات العشوائية؛ تغيير أي قيمة يحوّل الملف إلى مخصص. أندرويد يستخدم افتراضياً
  متوازن + DoT؛ سطح المكتب يستخدم متوازن + UDP.
- **المفضلة.** أضف نجمة إلى خادم في الخوادم أو في بطاقة نتيجة، ثم صفِّ حسب المفضلة أو شغّل
  **اختبار المفضلة**.
- **توصيات مشروحة.** شاهد أسرع خادم موصى به، وأسرع خادم عادي يمكن لسطح المكتب تطبيقه، وأسرع
  خادم مشفر قيس في هذا الاختبار، والفرق عن DNS الحالي، وتنبيهات التقارب، وأسباباً بلغة واضحة.
- **اتجاهات السجل ومقاييس مفصلة.** مخطط لمعدل الفائز، والملف والعمق في كل إدخال سجل، وزمن
  الاستجابة المخزن وغير المخزن، والتذبذب والمهلات وDNSSEC وحالة الاعتراض وتفاصيل الأمان لكل
  خادم.
- **قارن بما لديك.** توصية تضع علامة **IN USE** على خادم مُعدّ بالفعل، وتوضح عناوين DNS الحالية
  التي سيستبدلها التطبيق.
- **اختبر الكل أو المحدد أو المفضلة أو DNS الحالي.**
- **UDP وTCP وDNS-over-TLS وDNS-over-HTTPS.** يستخدم DoH استعلامات بصيغة RFC 8484 ويدعم كل نوع
  استعلام يستخدمه الاختبار، بما في ذلك AAAA وDNSSEC.
- **فحوص أمان DNS.** يفحص dnsrace التحقق من DNSSEC والتوقيعات المكسورة عمداً، إضافة إلى اعتراض
  NXDOMAIN. لا يُوصى بخادم يقبل إجابة DNSSEC مزيفة ولا يُطبَّق أبداً.
- **التطبيق والاستعادة على Linux وWindows وmacOS.** يُحفظ إعداد الخادم السابق قبل التغيير،
  ويستطيع التطبيق استعادته لاحقاً.
- **السجل والتقارير.** تُحفظ آخر 20 عملية محلياً ويمكن إعادة فتحها. تصدير سطح المكتب يدعم JSON
  وCSV وHTML وملخصاً نصياً؛ ويشارك أندرويد تقريراً نصياً عبر ورقة المشاركة. تسجل التقارير ملف
  الاختبار وعمقه.
- **ثماني سمات:** النظام، داكن، فاتح، Midnight، Nord، Solarized Light، Dracula، وتباين عالٍ.
  **النظام** يتبع تفضيل النظام للفاتح/الداكن.
- **خوادم مخصصة وفحوص توجيه وإعدادات محفوظة.**
- **نسخ احتياطي ونقل للخوادم.** صدّر الخوادم المخصصة والمفضلة بصيغة JSON، ثم استوردها وادمجها
  على جهاز آخر. تُتجاوز التكرارات وتُبلَّغ الإدخالات غير الصالحة.
- **تقرير تشخيص.** انسخ الإصدار ونظام التشغيل واللغة والسمة والملف وDNS الحالي وآخر اختبار وحالة
  التحديث ومسارات الإعدادات في كتلة نصية واحدة لطلبات الدعم.
- **واجهة سطر أوامر.** يشغّل `dnsrace --cli` المحرك نفسه دون نافذة، ويطبع جدولاً مرتباً ويمكنه
  تصدير JSON أو CSV. متاح في بناءات سطح المكتب.
- **بلا تتبع وبلا حساب وبلا صلاحيات جذر وبلا خدمة خلفية.**

## التنزيل

| النظام | الملف |
| --- | --- |
| Linux x86_64 | `dnsrace-0.9.0-x86_64.AppImage` |
| Linux aarch64 | `dnsrace-0.9.0-aarch64.AppImage` |
| Windows x86_64 | `dnsrace-0.9.0-windows-x86_64.zip` |
| macOS Intel | `dnsrace-0.9.0-macos-x86_64.zip` |
| macOS Apple silicon | `dnsrace-0.9.0-macos-aarch64.zip` |
| أندرويد 8.0 فأحدث | `dnsrace-0.9.0-android-release-debugkey.apk` |

يتضمن كل إصدار ملف `SHA256SUMS.txt`؛ ولكل AppImage وملف APK ملف `.sha256` خاص به. تُنشئ
الدفعات إلى `main` بناءات لقطة منفصلة عبر سير عمل **Main snapshot**؛ تلك الملفات لقطات تطوير
وليست إصدارات موسومة.

ملف APK للإصدار 0.9.0 موقّع بمخزن مفاتيح أندرويد للتصحيح، وليس بمفتاح نشر Play Store. هذا
مناسب للتثبيت اليدوي والاختبار.

### Linux

```sh
chmod +x dnsrace-0.9.0-x86_64.AppImage
./dnsrace-0.9.0-x86_64.AppImage
```

إذا لم يكن FUSE متاحاً على نظامك، استخدم وضع استخراج وتشغيل AppImage:

```sh
./dnsrace-0.9.0-x86_64.AppImage --appimage-extract-and-run
```

يُبنى AppImage لـ x86_64 على Ubuntu 22.04 وaarch64 على Ubuntu 24.04؛ يحتاج كلاهما إلى glibc
ومكدس سطح مكتب حديثين نسبياً. يفضّل التطبيق Wayland الأصلي عندما يكون compositor متاحاً،
ويعود إلى X11 عند عدم توفره حتى لو كان XWayland موجوداً. يستخدم تثبيت إعدادات DNS أداة
NetworkManager (`nmcli`) عند
توفرها، وإلا systemd-resolved (`resolvectl`). قد يطلب سطح المكتب إذناً عبر polkit.

### Windows

فك ضغط الأرشيف وشغّل `dnsrace.exe`. تستخدم بناءات الإصدار نظام واجهة Windows الرسومية، لذلك لا
تفتح نافذة طرفية. يغيّر تطبيق DNS المحول النشط عبر PowerShell ويطلب إذن المسؤول بنافذة UAC.

### macOS

فك ضغط الأرشيف، انقل `dnsrace.app` إلى Applications، وافتحه. التطبيق غير موقّع بشهادة Apple
Developer ID، لذلك قد يتطلب التشغيل الأول النقر بزر الفأرة الأيمن على التطبيق واختيار **Open**،
أو تشغيل:

```sh
xattr -dr com.apple.quarantine dnsrace.app
```

يستخدم تطبيق DNS أداة `networksetup` ويطلب موافقة المسؤول. دعم macOS يُقدَّم على أساس أفضل جهد.

### أندرويد

1. نزّل `dnsrace-0.9.0-android-release-debugkey.apk`.
2. اسمح بالتثبيت من المتصفح أو مدير الملفات عندما يطلب أندرويد ذلك.
3. شغّل اختباراً، وافتح خادماً، واستخدم **إعداد هذا الخادم** لاتباع خطوات Private DNS
   (أندرويد 9 فأحدث) أو DNS لشبكة Wi-Fi (أندرويد 8.0–8.1).

أو ثبّت عبر USB:

```sh
adb install -r dnsrace-0.9.0-android-release-debugkey.apk
```

لا يسمح أندرويد لتطبيق عادي بتغيير Private DNS بصمت. لا يطلب dnsrace VPN أو صلاحية جذر أو خدمة
خلفية؛ بل يقيس الخوادم ويسلّمك القيمة لإدخالها. تُشارك التقارير كنص، لذلك لا يحتاج التطبيق إلى
إذن تخزين أو مجلد تصدير.

## التحديثات

يتحقق dnsrace من أحدث إصدار على GitHub عند بدء التشغيل، ما لم تُطفئ **التحقق تلقائياً عند البدء**
في الإعدادات. يشغّل **التحقق من التحديثات** في الإعدادات الفحص نفسه عند الطلب. يعرض الإصدار
الأحدث ملاحظات إصداره وإجراء تنزيل.

- **Linux AppImage وWindows وmacOS:** يُنزَّل الأرشيف، وتُتحقق بصمة SHA-256 مقابل ملف الإصدار
  `SHA256SUMS.txt`، ثم يثبّت التطبيق الإصدار الجديد في مكانه ويعيد التشغيل. أي فشل في الفحص أو
  البصمة يترك الإصدار الحالي دون تغيير.
- **أندرويد:** لا يسمح أندرويد للتطبيق باستبدال نفسه بصمت. ينزّل dnsrace ملف APK الجديد ويفتح
  مثبّت النظام لتأكيد التحديث.

لا توجد قناة تحديث أو تخطٍّ لإصدار: هناك مسار إصدار مستقر واحد.

## اللغة والتخطيط من اليمين إلى اليسار

الإعدادات ← المظهر ← اللغة تعرض **النظام** و**English** و**العربية**. يتبع **النظام** لغة
الجهاز. تبدّل العربية كل الشاشات إلى اتجاه من اليمين إلى اليسار: ينتقل شريط سطح المكتب إلى
اليمين، وينعكس تنقل الهاتف، وتُحاذى محتويات البطاقات إلى اليمين، وتتبع الجداول وصفوف النتائج
اتجاه القراءة. يغطي خط Noto Sans Arabic المضمّن النص العربي دون خط من النظام، وتبقى الواجهة
قابلة للاستخدام بالإنجليزية على التثبيت نفسه.

تبقى أسماء الخوادم والعناوين والقيم التقنية بالحروف اللاتينية، وكذلك مفاتيح JSON وCSV، لتعمل
البرامج النصية والتقارير المحفوظة عبر اللغات.

## سطر الأوامر

محرك الاختبار نفسه متاح دون نافذة:

```sh
dnsrace --cli                          # الدليل الافتراضي، جدول مرتب
dnsrace --cli --profile quick --top 10
dnsrace --cli --protocol dot --json result.json --csv result.csv
dnsrace --cli --list                   # اعرض ما سيُختبر
dnsrace --cli --help
```

يذهب التقدم إلى stderr والجدول إلى stdout، لذلك يعمل `dnsrace --cli > result.txt`. استخدم
`--all` لكل الدليل، و`--no-system` لتجاوز خوادم النظام الحالية، و`--timeout` و`--jobs`
و`--repeat` و`--family` لقيود مخصصة. تحتفظ JSON وCSV بمفاتيح إنجليزية ثابتة للبرامج النصية.
يستخدم ملف Windows للإصدار نظام واجهة رسومية، لذلك تُقصد واجهة سطر الأوامر لبناءات Linux وmacOS
(أو بناء Windows للتطوير من طرفية).

## الاستيراد والتصدير والتشخيص

يمكن لـ الإعدادات ← البيانات تصدير الخوادم المخصصة والمفضلة إلى ملف JSON واستيرادها على جهاز
آخر. يدمج الاستيراد الإدخالات، ويتجاوز التكرارات والبروتوكولات غير الصالحة، ويبلغ بعدد الإدخالات
المضافة. يظهر مسار التصدير الافتراضي في الإعدادات ويمكن تجاوزه بحقل المسار.

ينسخ **نسخ التشخيص** في الإعدادات تقرير دعم نصياً بسيطاً: الإصدار ونظام التشغيل والمعمارية
واللغة والسمة والملف والعمق وDNS الحالي وآخر اختبار وحالة التحديث وعدد السجل والخوادم المخصصة
والمفضلة ومسارات الإعدادات. لا يحتوي على تتبع ولا بيانات حساب.

## استخدام dnsrace

1. **تحقق مما تستخدمه.** يكتشف dnsrace خوادم DNS للنظام في الخلفية عند البدء. تعرض بطاقة DNS
   الحالي الواجهة النشطة ومصدر الكشف والعناوين المعروفة بمزودها. استخدم **تحديث الكشف** بعد
   تغيير الشبكة، أو **اختبار الحالي** لقياس تلك الخوادم بالضبط، أو **نسخ DNS الحالي** على سطح
   المكتب لنسخ العناوين.
2. **اختر البروتوكول وعائلة العناوين.** UDP هو الخيار العادي لسطح المكتب. يساعد TCP على الشبكات
   التي تحجب UDP أو تعبث بحزمة المنفذ 53. DoT هو الافتراضي في تثبيت أندرويد الجديد. يقيس DoT
   وDoH خوادم مشفرة؛ ولا يستطيع سطح المكتب تطبيقهما كخادم نظام.
3. **اختر الخوادم.** ابحث، وصفِّ حسب الفئة أو النقل أو عائلة العناوين أو المفضلة، وحدد صفوفاً
   فردية، أو استخدم التحديد الافتراضي. **اختبار المحدد** يقيس الخوادم المحددة فقط؛ **اختبار
   الكل** يقيس كل الدليل للبروتوكول الحالي.
4. **ابدأ الاختبار.** يفحص التطبيق كل المرشحين سريعاً، ثم يختبر المستجيبين اختباراً كاملاً. تظهر
   الصفوف مع انتهاء الخوادم، لذلك تشاهد التقدم بدلاً من انتظار نافذة فارغة. على سطح المكتب،
   رتّب حسب أي عمود وانقر مرة أخرى لعكس الترتيب.
5. **راجع التوصية.** تعرض البطاقة أسرع خادم موصى به، وزمن الاستجابة المخزن وغير المخزن، وحالة
   DNSSEC، والأسباب، والفرق عن DNS الحالي. تضع علامة **IN USE** على خادم مُعدّ بالفعل. اختر
   صفاً آخر بـ **استخدام هذا الخادم** على سطح المكتب أو **إعداد هذا الخادم** على أندرويد؛ تتبع
   البطاقة اختيارك.
6. **نفّذ النتيجة.** على سطح المكتب، يطلب **تطبيق DNS** التأكيد ويغيّر الاتصال النشط. تُكتب
   الإعدادات السابقة في `applied.json`، ويعيد **استعادة DNS السابق** إعدادها. على أندرويد، اتبع
   دليل الإعداد وأدخل اسم المضيف أو العناوين في إعدادات النظام.

يمكن تطبيق خوادم DNS العادية على المنفذ 53 فقط. إدخالات DoT وDoH للقياس فقط على سطح المكتب.
يُمنع تطبيق خادم بنتيجة DNSSEC مزيفة؛ ويمكن تطبيق نتائج صحية أخرى مع تحذير إذا اخترته صراحة.
على أندرويد، يُوسم الاختيار الذي يحتوي فقط على اسم مضيف DoT للمزود بـ **«اسم مضيف DoT للمزود —
لم يُقس في هذا الاختبار»** ويعرض الدليل اختبار DoT.

### الكشف التلقائي

| النظام | المصادر |
| --- | --- |
| Linux | بيانات systemd-resolved لكل وصلة، واتصال NetworkManager النشط، والمسار الافتراضي، و`/etc/resolv.conf`، وملف upstream لـ systemd-resolved. |
| Windows | `Get-NetIPConfiguration` عبر PowerShell، مع بديل `pwsh` وبديل سجل مستقل عن اللغة. |
| macOS | `scutil --dns` وترتيب خدمات `networksetup` وقيم DNS، إضافة إلى المسار الافتراضي. |
| أندرويد | خصائص ارتباط ConnectivityManager والشبكة النشطة. |

يعمل الكشف بشكل غير متزامن، لذلك لا يؤدي أمر نظام بطيء أو مفقود إلى تأخير الإطار الأول. وعندما
لا يعطي أي مصدر عنواناً، تقول الواجهة ذلك ويبقى بقية التطبيق يعمل.

اختر سمة في الإعدادات: **النظام**، **داكن**، **فاتح**، **Midnight**، **Nord**، **Solarized
Light**، **Dracula** أو **تباين عالٍ**. **النظام** يتبع تفضيل النظام للفاتح/الداكن. تبقى
السمات الثماني على المنصتين.

اختصارات سطح المكتب:

| الاختصار | الإجراء |
| --- | --- |
| Ctrl/Cmd+R أو F5 | تحديث كشف DNS |
| Ctrl/Cmd+Enter | اختبار المحدد |
| Ctrl/Cmd+Shift+Enter | اختبار الكل |

### معنى الأعمدة

| العمود | المعنى |
| --- | --- |
| مخزن | متوسط زمن الاستجابة للنطاقات الشائعة التي يُرجح أن الخادم خزّنها. |
| غير مخزن | متوسط زمن الاستجابة لأسماء عشوائية تفرض استعلاماً عودياً. |
| النتيجة | قيمة ترتيب مدمجة. تدفع عقوبات الصحة والاعتراض الخوادم السيئة إلى الأسفل. |
| DNSSEC | محقق، غير آمن، جزئي، غير معروف، أو مزيف مقبول. |
| الحالة | جيد، تحقق، غير موثوق أو يعترض، بناءً على الاختبار الكامل. |

## الإعدادات والخصوصية

تُحفظ الإعدادات والسجل وحالة التطبيق المحفوظة في مجلد إعدادات النظام:

| النظام | المجلد |
| --- | --- |
| Linux | `~/.config/dnsrace/` |
| Windows | `%APPDATA%\dnsrace\` |
| macOS | `~/Library/Application Support/dnsrace/` |
| أندرويد | التخزين الداخلي الخاص بالتطبيق |

الملفات هي `settings.json` و`history.json` و`applied.json`. السجل محدود بـ 20 اختباراً. عيّن
`DNSRACE_CONFIG_DIR` على سطح المكتب لاستخدام مجلد مختلف، وهو مفيد للإعدادات المحمولة أو
الاختبارات. يستخدم أندرويد مسار بياناته الداخلي مباشرة؛ وتخرج التقارير من التطبيق عبر ورقة
المشاركة بدلاً من مسار ملف.

لا يرسل dnsrace تتبعاً. أثناء الاستخدام العادي يتصل بنقاط نهاية الخوادم التي يجري اختبارها
ويسأل Cloudflare ‏1.1.1.1 عن سجل CHAOS ‏`id.server` المستخدم لعرض الحافة. المزايا الاختيارية
تضيف طلبات: نقطة تتبع HTTPS لدى Cloudflare وpublic-dns.info عند تفعيل **تضمين الخوادم المفتوحة
القريبة**. تُكتب صادرات سطح المكتب في Downloads افتراضياً، أو في المجلد المختار في الإعدادات.

## البناء من المصدر

تحتاج إلى Rust **1.100.0** (يثبّته المستودع في `rust-toolchain.toml`) وبيئة بناء سطح مكتب
عاملة. على Debian/Ubuntu:

```sh
sudo apt-get install build-essential pkg-config \
  libgl1-mesa-dev libegl1-mesa-dev libfontconfig1-dev \
  libwayland-dev libxkbcommon-dev libxkbcommon-x11-dev \
  libx11-dev libxcursor-dev libxi-dev libxrandr-dev

cargo build --release --locked
./target/release/dnsrace
```

ابنِ AppImage لـ Linux محلياً:

```sh
cargo run -p xtask -- appimage 0.9.0 x86_64 target/release/dnsrace dist
```

يجمع الأمر AppDir، ويتحقق من مدخل سطح المكتب وبيانات AppStream عند توفر الأدوات، وينزّل
`appimagetool` عند الحاجة، ويكتب `dist/dnsrace-0.9.0-x86_64.AppImage` مع ملف `.sha256`.

### ملف APK لأندرويد

تحتاج إلى Java 17، ومنصة Android SDK 36، وأدوات البناء 36.0.0، وNDK **30.0.16248370**،
و`cargo-apk` 0.10.0. إن NDK r27 قديم جداً لـ compileSdk 36.

```sh
rustup target add armv7-linux-androideabi aarch64-linux-android x86_64-linux-android
cargo install cargo-apk --version 0.10.0 --locked

export ANDROID_HOME="$HOME/Android/Sdk"
export ANDROID_NDK_HOME="$HOME/Android/android-ndk-r30"

cargo apk build --lib              # APK للتطوير
cargo apk build --lib --release    # APK للإصدار
```

`--lib` مطلوب لأن الحزمة تحتوي أيضاً على برنامج سطح مكتب. يُوقّع بناء الإصدار بمتغيرات
`CARGO_APK_RELEASE_KEYSTORE` و`CARGO_APK_RELEASE_KEYSTORE_PASSWORD` و
`CARGO_APK_RELEASE_KEY_ALIAS` و`CARGO_APK_RELEASE_KEY_PASSWORD` عند تعيينها؛ ويستخدم ملف إصدار
0.9.0 مخزن مفاتيح التصحيح ما لم توفر أسرار CI مفتاحاً خاصاً.

شغّل الاختبارات والفحوص:

```sh
cargo fmt --all -- --check
cargo test --locked
cargo clippy --all-targets --locked -- -D warnings
```

يُغطى المحرك ومحللات المنصات باختبارات وحدة وتكامل؛ وتستخدم اختبارات التكامل خوادم DNS محاكاة
على loopback ولا تفتح نافذة. تستخدم اختبارات الواجهة `egui_kittest` لعرض كل صفحة بأحجام سطح
المكتب والهاتف والأفقية، والنقر على عناصر التحكم الموسومة، والتحقق من إمكانية الوصول وأحجام
اللمس والنص الكبير والمناطق الآمنة.

## بنية المشروع

- `src/gui/` — الواجهة المتكيفة: `app.rs` (الحالة والآثار)، `state.rs`، `actions.rs`،
  `backend.rs`، `desktop.rs`، `mobile.rs`، `pages/`، `modals.rs`، `components.rs`، `theme.rs`،
  `icons.rs` و`tests/`.
- `src/engine.rs` — مسار الاختبار المشترك بين الواجهة والاختبارات.
- `src/bench.rs` — الفحص السريع والاختبارات الكاملة وDNSSEC والاعتراض والتوجيه.
- `src/providers.rs` — دليل الخوادم المدمج وتحديد المزود.
- `src/recommend.rs` — نموذج التوصية والفروق وحالات التقارب والأسباب.
- `src/android_guide.rs` — دليل إعداد Private DNS وWi-Fi DNS.
- `src/android.rs` — مضيف JNI لنظام أندرويد وحدود المناطق الآمنة والمشاركة والنوايا.
- `src/system.rs` — كشف DNS الحالي عبر المنصات ومحللاتها.
- `src/platform.rs` — تنفيذ التطبيق والاستعادة على Linux وWindows وmacOS.
- `src/report.rs` — تقارير JSON وCSV وHTML والملخص.
- `src/i18n.rs` — نصوص الإنجليزية والعربية واختيار لغة النظام وأدوات RTL.
- `src/update.rs` — فحص إصدارات GitHub والتحقق من SHA-256 ومثبّتات المنصات.
- `src/cli.rs` — اختبار `--cli` بدون واجهة.
- `src/diagnostics.rs` — تقرير الدعم القابل للنسخ.
- `src/transfer.rs` — استيراد وتصدير الخوادم المخصصة والمفضلة.
- `src/config.rs` — حفظ الإعدادات والسجل وحالة التطبيق.
- `packaging/` — أصول AppImage وموارد أندرويد وسكربت بناء الأيقونة.

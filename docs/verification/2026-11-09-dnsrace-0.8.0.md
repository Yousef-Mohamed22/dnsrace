# dnsrace 0.8.0 verification

Date: 2026-11-11
Plan: `docs/superpowers/plans/2026-11-09-dnsrace-0.8.0.md`
Target: dnsrace 0.8.0, desktop plus Android 8.0+ (API 26+)

## Environment

- Rust 1.99.1, edition 2024, eframe/egui 0.37, egui_kittest 0.37.
- Desktop gates were run on Linux.
- Android build: JDK 17, Android SDK 36, build-tools 36.0.0, NDK r30
  (`30.0.16248370`), cargo-apk 0.10, universal ABIs.
- Device: Redmi A7 Pro, Android 16 (API 36), 720x1600 px at 320 dpi (360x800 dp).
- Android 8.0 emulator: `dnsrace-api26`, x86_64, Android 8.0 (API 26), 720x1440 px at
  320 dpi (360x720 dp). The physical Huawei Y7 2018 could not be used because its USB data
  pins never enumerate (`device not accepting address … error -71`); several cables, ports,
  reboots and port cleaning all failed.

## Bugs found and fixed during device verification

- Private DNS intent missing on HyperOS: fall back to `WIRELESS_SETTINGS`, then `SETTINGS`,
  and trim Java stack traces from notices.
- Long detail-sheet titles painted under the close button; switched to `egui::Sides` with
  `shrink_left` and hid the desktop-only Apply control on Android.
- Stale selected/favourite IDs could enable empty run scopes; scope counts now use
  `selected_in_catalog()` / `favourites_in_catalog()`.
- History labels showed `UTC` twice; `HistoryEntry::label()` now formats once.
- About opened above the viewport; opening it now requests a one-shot scroll to the card.
- Back left a reused zombie process that hung on relaunch; an `is_finishing` watchdog now
  exits the process after the activity finishes.
- Custom-resolver Edit/Remove painted over the resolver name on a 360 dp row; the actions
  now wrap, with a regression test asserting the rects never intersect.
- Clippy debt from the GUI split was cleared so the release gate is warning-free.
- The filled favourite star rendered as a mangled convex fill on Android; it is now a
  ten-triangle centre fan and a geometry regression test covers the outline area.
- Copy on API 26 threw `Can't create handler inside thread that has not called
  Looper.prepare()`; the JNI thread now prepares a Looper before constructing
  `ClipboardManager`.
- The mobile row-detail sheet inherited the previous scroll offset and clipped its title; it
  now uses a fresh scroll identity for each opening.

## Not covered on hardware

- Android 8.0–8.1 on physical hardware: the API 26 runtime path was exercised on the
  x86_64 emulator, but the Huawei Y7 2018 could not be connected over ADB.
- Play Store signing: this APK is debug-key signed. A production keystore can be supplied to
  the release workflow later.
